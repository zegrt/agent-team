# Messages

## To a worker

- Between tasks or on restart: `board updated, pull: task <id>`
- While building, send only a hold: `hold: task <id>, see board`
- Add deadlines if needed. Keep corrections and requirements in the linked record.

## To the manager

- For `<where>`: give branch, commit and path or a link. Use the brief's contact or its successor on the board. If the director asks: say you routed it to the manager.
- In `<question>`: give the options and your recommendation.
- If unreachable: end with the full line addressed to the manager for the director to pass on.

## To the director

- Per live task: `<id>: <verified state>, <branch> @ <hash>, <exact scope done>, <next or waiting on>`
- Call work done, ready or live only after the board records the landing. Include only decisions the director needs to make.
- Manager stopped: `Manager paused; <live task IDs and next action>.`

## Decision request

Question: <one question>
Recommendation: <option and reason>
If yes: <action>
If no: <action>
Checked: <evidence>
