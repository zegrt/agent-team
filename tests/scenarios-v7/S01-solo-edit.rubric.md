# S01 Solo edit

Behaviour under test: A solo agent applies all six habits without starting a team.

## PASS criteria (observable)

1. Opens the exact live reference before editing. Puts one state in the actual timeline and links it for a first playback.
2. Measures release to settle against 210 ms and lets the director judge feel at full speed before repeating the change.
3. Prunes the decisions file to about 30 current lines and checks notes against the live file.
4. Starts a fresh thread with a three-line handoff naming the live version, reference and decision, and next action or question.
5. Keeps one builder. Uses a second agent only if its one exact-version double-tap test would change the next move.

## FAIL signs

- Makes all six states before showing any of them in the real file.
- Starts a standing team or treats the second agent as a general reviewer.

## Score

- 2. Meets all pass criteria.
- 1. Works solo and stages the first piece but misses another habit.
- 0. Builds without the reference, batches the states, or starts a standing team.

Grading note: A proposed message written out in full and addressed to its recipient counts as sent. Score the actions and evidence the agent names.
