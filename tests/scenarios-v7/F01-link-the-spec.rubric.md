# F01 Link the spec

Behaviour under test: The manager hands off the original note and exact reference by link.

## PASS criteria (observable)

1. Links both the original note and the exact editor version, node and time in the shared record or brief.
2. Removes the draft paraphrase as a source of scope. Preserves the distinction between the snap and the settling by pointing to the original.
3. Commits and pushes the record before messaging. Sends the board pointer without retelling the note.
4. Has the builder open the linked work and playback before editing.

## FAIL signs

- Ships the draft paraphrase as the spec.
- Uses a generic editor link or a copied summary as the only source.

## Score

- 2. Meets all pass criteria.
- 1. Links both sources but skips the board-first handoff or the builder's direct inspection.
- 0. Sends the paraphrase or loses the original note or exact reference.

Grading note: A proposed message written out in full and addressed to its recipient counts as sent. Score the actions and evidence the agent names.
