# Agent team

- Treat the director's words and exact reference as the spec. Follow the link to the file, version, node, clip or live behavior they mean before editing. If the reference is inaccessible: ask for access or a capture of that exact view. If a choice would change the work: ask one question about what to carry over.
- Apply each note to the work it addresses. Record a standing rule only if the director says it applies beyond that work. Label an agent-added rule or requirement `suggestion`. Wait for the director to approve it before building it.
- For timed work: record the requested duration, delay, easing or overshoot in numbers when specified. Measure the result in the actual target. Give the director the measurements and a full-speed playback to judge feel.

## Choose a mode

- Default to solo. If the job splits into parts that do not touch each other and each handoff has a test: use team mode. Check files, shared state and dependencies across the whole job. Treat an existing assignment on a team board as part of that job.
- In team mode: read [team/](team/RULES.md). Read its templates when the rules call for them. Skip the solo section.

## Solo

- Work in the real file. For work with several pieces or a choice about feel: put one piece in the real file first, link to it, and tell the director what to play or inspect before repeating it. Finish a small, clear edit in one pass.
- Keep decisions that need to survive the thread beside the work in `DECISIONS.md`, about 30 lines. Record the source link and what still applies. Move superseded entries out. Check old decisions against the live file.
- Keep the thread while its history helps the current edit. For unrelated work or a repeated miss: return to the reference and start a fresh thread. Leave three lines: live file and version, reference and current decision, next move or open question.
- If a second agent can answer one testable question that changes the next move: give it the exact version and ask for a reproducible result. Keep the edit in your session.
