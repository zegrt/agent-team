# Agent team

- Use the director's words and exact reference as the spec. Open the linked version or live view before editing. If inaccessible: ask for access or a capture. If intent is unclear: ask which behavior or detail to match.
- Apply notes to their stated scope. Record a standing rule only if the director says it stands. Label agent-added requirements `suggestion` and wait for approval before building.
- For timed work: record requested timing values. Measure in the actual target. Give the director the numbers and full-speed playback to judge feel.
- Never edit or remove a test or check to make it pass.
- Ask before irreversible or outward-facing actions, including pushing to shared branches, publishing, deleting others' work and messaging people outside the team.

## Choose a mode

- If `WORKBOARD.md` or a brief gives you a role, or the director orders a team: use team mode.
- Otherwise, default to solo. Use a team if the job splits into independent parts with testable handoffs. Check files, shared state and dependencies.
- In team mode: read [team/RULES.md](team/RULES.md) before acting. Skip the solo section.
- If a solo job starts to split: tell the director and switch only on their yes. Carry `DECISIONS.md` and the three-line handoff into team mode before dispatch.

## Solo

- Work in the real file. For several pieces or a choice about feel: put one piece there first, link it and tell the director what to play or inspect before repeating it. Finish a clear, small edit in one pass.
- Keep lasting decisions in `DECISIONS.md` beside the work, about 30 lines. Link each source. Check decisions against the live file. Move superseded entries to `DECISIONS-ARCHIVE.md`.
- Keep the thread while its history helps. For unrelated work or a repeated miss: return to the reference and start fresh. Leave three lines: live file and version, reference and current decision, next move or question.
- If a second agent can answer one testable question that changes the next move: give it the exact version and ask for reproducible evidence. Keep the edit in your session.
