# Inbox

Use this folder for corrections to how the skill works across projects. Keep project-specific directions in the project's own record. A direction becomes a standing rule only when the director gives it standing scope.

Link the original direction from the relevant project board or decision record. If a process correction keeps recurring, send a privacy-safe account to the maintainer with the director's permission. Include what happened, what behavior should change and the affected rule or form. Use a new file named `<date>-<short-name>.md` or open a [GitHub issue](https://github.com/zegrt/agent-team/issues).

The maintainer edits [SKILL.md](../SKILL.md) or [team/](../team/RULES.md) after approval and adds a scenario for changed behavior. Move background to the [design notes](../docs/DESIGN.md). Close the inbox entry when the change lands.
